# Security Operations Center (SOC) - Incident Monitor Dashboard

A responsive web dashboard designed to simulate a Security Operations Center (SOC) monitoring interface. It provides visibility into real-time security events, categorizes incidents by severity, and offers quick search and filtering capabilities.

---

## 📌 Features

- **System Health Indicator:** Real-time online status monitor for SOC infrastructure.
- **Severity Metrics Cards:** Overview counters tracking incident frequency across Critical, High, Medium, and Low tiers.
- **Keyword Search:** Instant client-side search filtering through incident descriptions and IDs.
- **Severity Filtering:** Dynamic dropdown filter to isolate events by threat level.
- **Incident Feed:** Color-coded feed detailing alerts, descriptions, and timestamps.
- **Responsive Layout:** Optimized for desktop and mobile screen viewports.

---

## 🛠️ Built With

- **HTML:** Semantic markup structure.
- **CSS:** Custom responsive layout using Flexbox and CSS Grid (Dark/Slate SOC theme).
- **JavaScript (Vanilla):** DOM manipulation, event handling, and dynamic filtering logic.
- **AOS (Animate On Scroll):** Smooth element scroll animations.
